# YClaw AI 运营助手 — 详细设计方案

> **定位**：YClaw 的 AI 运营助手不是通用聊天机器人，而是**深度嵌入工作流上下文的智能副驾驶**。它理解你的自动化任务、股票策略、浏览器操作和插件状态，能主动发现问题、推荐操作、解释异常、生成报告。

## 1. 设计理念

### 1.1 三个核心原则

```
原则一: 上下文感知
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
AI 助手不是孤立存在的, 它必须"看到"用户当前在做什么:

  用户在编辑自动化任务 → 助手理解任务上下文, 帮助优化步骤
  用户在查看股票图表 → 助手理解当前股票和指标, 提供分析
  用户在浏览器模块   → 助手理解当前页面, 辅助采集规则编写

  ❌ 错误做法: 通用聊天窗口, 用户需要手动描述上下文
  ✅ 正确做法: 助手自动感知当前模块/任务/数据, 无缝衔接


原则二: 可验证的执行
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
助手生成的每一步操作都必须可预览、可撤销、可审计:

  用户: "帮我创建一个每天 9 点采集茅台价格的任务"
  助手: 不直接执行, 而是生成操作预览:

    ┌─────────────────────────────────────────────┐
    │ 🤖 我将为你执行以下操作:                      │
    │                                             │
    │ 1. 创建自动化任务 "茅台价格监控"              │
    │    - 触发: 每天 09:00 (Cron)                 │
    │    - 步骤1: 打开 https://quote.eastmoney.com │
    │    - 步骤2: 定位 #price 元素                 │
    │    - 步骤3: 提取价格数据                     │
    │    - 步骤4: 存入 SQLite                      │
    │                                             │
    │    [✅ 确认执行]  [✏️ 修改]  [❌ 取消]        │
    └─────────────────────────────────────────────┘


原则三: 渐进式信任
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
不同操作需要不同级别的用户确认:

  Level 0 (免确认): 查询类 — "今天执行了哪些任务?"
  Level 1 (轻确认): 低风险操作 — "打开股票分析页面"
  Level 2 (预览确认): 中风险操作 — "创建自动化任务"
  Level 3 (显式授权): 高风险操作 — "删除所有采集数据"
```

### 1.2 与通用 AI 助手的区别

| 维度 | 通用 AI (ChatGPT/文心) | YClaw AI 运营助手 |
|------|:---------------------:|:----------------:|
| 上下文 | 用户手动输入 | 自动感知当前模块/任务/数据 |
| 执行能力 | 只能生成文本 | 可直接操作 YClaw 内部功能 |
| 数据访问 | 无法访问本地数据 | 可读写任务、股票、插件、日志数据 |
| 实时性 | 训练数据截止日期 | 实时获取系统状态、行情、任务结果 |
| 主动性 | 被动等待提问 | 主动发现问题并推送建议 |
| 操作范围 | 无 | 仅限 YClaw 平台内（沙箱隔离） |

```

├─────────────────────────────────────────────────────────────┤
│                                                             │
│ 🔍 任务分析                                                 │
│    "这个任务为什么失败了?"                                   │

│                                                             │

│    → 统计近 7 天数据, 生成趋势描述                          │
│    → 识别异常波动, 关联可能原因                             │
│    → 预测未来趋势                                           │
│                                                             │
│ 🧠 数据解读                                                 │
│    "帮我分析一下茅台最近的走势"                               │
│    → 读取 K 线数据和技术指标                                │

│                                                             │
│ 📋 日志解读                                                 │
│    "系统最近有什么异常吗?"                                   │
│    → 扫描近 24 小时日志                                     │
```

```typescript
  localMatch(message: string): ResolvedIntent | null;
}
```

## 总结

YClaw AI 运营助手的核心价值在于**将 AI 的理解能力与 YClaw 的执行能力打通**：

1. **它不只是聊天** — 每一句对话背后都连接着真实的工具调用和系统操作
2. **它不只是被动** — 通过事件订阅主动发现问题、推送建议
3. **它不只是通用** — 深度理解 YClaw 的任务、行情、插件等业务上下文

最关键的落地建议：**先做 Phase 1 的基础对话 + 3 个核心工具**，让用户能通过自然语言查询任务状态和系统信息。这个最小可用版本就能显著提升使用体验，后续再逐步扩展工具和主动智能能力。
