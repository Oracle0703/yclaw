# JD Signin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有自动签到中心新增京东 PC 签到领京豆，并在执行结果中返回本次到账京豆和当前余额。

**Architecture:** 复用现有 `signin` 任务、运行记录、浏览器会话和状态卡。京东签到采用浏览器会话混合模式：页面负责触发带动态签名的签到请求，自动化脚本负责前后查询 `BEAN_BALANCE`、点击“PC签到领京豆”、再用余额差值和 `BEAN_DETAILS_NOCNT` 验证到账。

**Tech Stack:** Electron main process, React/Vite renderer, TypeScript, Vitest.
